# Hanken Grotesk

Figure 1 uses the same Latin typeface as https://vaclis.net/ (verified in `assets/css/site.css?v=21` on 2026-10-01). Regular (400) and SemiBold (600) match its body and heading weights.

Source: https://github.com/google/fonts/tree/main/ofl/hankengrotesk
The two static TTFs are instances of upstream `HankenGrotesk[wght].ttf`, generated with fontTools 4.63.0 `instantiateVariableFont(..., {"wght": weight}, updateFontNames=True)` at weights 400 and 600. They are bundled under the SIL Open Font License in OFL.txt so reproduction does not require font downloads or system installation.

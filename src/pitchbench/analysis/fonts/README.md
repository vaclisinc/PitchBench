# Hanken Grotesk

Figure 1 uses Hanken Grotesk Regular (400) for descriptions and ExtraBold (800)
for headings. Both fonts are bundled for deterministic rendering.

Source: https://github.com/google/fonts/tree/main/ofl/hankengrotesk
The two static TTFs are instances of upstream `HankenGrotesk[wght].ttf`, generated with fontTools 4.63.0 `instantiateVariableFont(..., {"wght": weight}, updateFontNames=True)` at weights 400 and 800. They are bundled under the SIL Open Font License in OFL.txt so reproduction does not require font downloads or system installation.

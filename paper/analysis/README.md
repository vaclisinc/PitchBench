# Diagnostic analysis sample

These records use the separate analysis presets and support Table 2's ablations.
They are not the 5,802-stimulus benchmark sample. Use
[Table 1](../figures-and-tables/table1.md) for the 28-task model comparison.

`accuracies_combined.csv` is the numeric input to
`pitchbench.analysis.ablation.build_ablation_csv`; individual answer JSONs and
CSVs retain the supporting responses and conditions. Solfège and MCQ are
additional diagnostic conditions and do not contribute to Table 1.
